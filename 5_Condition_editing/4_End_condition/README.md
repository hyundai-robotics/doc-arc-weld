# 5.4 용접 종료 조건

Arc용접 설정이 디지털이고 용접시작조건 대화상자에서 [종료조건] 키를 누르면 다음과 같은 용접종료조건 편집화면이 나타납니다.

![](../../_assets/5_4_1.png)<br>
*그림 5.4.1. 용접종료조건 설정 (디지털 EWM 용접기 예)* 


용접 종료 조건의 항목을 수정 후 `ESC`키를 누르면 수정된 내용을 저장하지 않고 용접시작조건 대화상자로 이동합니다. `완료`키를 누르면 수정된 내용을 저장하고 용접시작조건 대화상자로 이동합니다.

</br>

---
각 항목별 내용은 다음과 같습니다.


</br>

### (1)	종료 용접전류/용접파워/송급속도  
크레이터 처리시 출력할 전류의 값을 설정합니다. 본 조건(시작조건의 용접전류, 용접파워, 송급속도) 대비 % 량으로 설정합니다. 단, EWM 용접기의 경우 본 조건과 같은 m/min으로 설정합니다.
<center>

| 지원 용접기 | 명칭 | 단위 | 범위 | 기본값 |
| :---: | :---: | :---: |:---: | :---: |
| 효성 | 종료 용접 전류 | A |28.0 ~ 350.0 | 28.0 |
| EWM | 종료 송급속도 | m/min | 0.0 ~ 25.0 | 2.17 |
| Fronius(TPS) | 종료 용접파워 | % | 10 ~ 100 | 70.0 |

</center>



### (2)	종료 용접 전압 / 종료 용접 전압 보정/ 아크 길이 보정  
크레이터 처리 시 출력할 전압(Arc 길이) 보정값을 설정합니다. 전압은 출력할 전압을 지정하여 출력합니다.
<center>

| 지원 용접기 | 명칭 | 단위 | 범위 | 기본값 |
| :---: | :---: | :---: |:---: | :---: |
| 효성(개별) | 종료 용접 전압 | V | 10.0 ~ 38.0 | 10.0 |
| 효성(시너직) | 종료 용접 전압 보정 | % | 50.0 ~ 150.0 | 50.0 |
| EWM | 종료 용접 전압 옵셋 | VP | -10.0 ~ 10.0 | 2 |
| Fronius(TPS) | 종료 아크 길이 보정 |  % | -30.0 ~ 30.0 | 0 |

</center>

### (3)	Downslope 시간(Crate Time): [ 0.10 ] 초 (범위: 0.0 ~ 10.0)  
본 조건과 종료조건 사이에 전류 변화를 슬로프로 처리하는 시간을 설정합니다.  

![](../../_assets/5_4_2.png)<br>
*그림 5.4.2. DownSlope 시간과 Crate 시간 차트*

### (4)	와이어 Burnback: [ 0 ] ms (범위: 0.0 ~ 200.0)  
Burnback 처리를 설정합니다. 용접기마다 상이할 수 있습니다.

### (5)	가스 후출: [ 0 ] 초 (범위: 0.0 ~ 10.0)  
Arc가 꺼진 후에도 보호가스를 계속 출력하는 시간을 설정합니다.

### (6)	크레이터 이동 시간: [ 0 ] 초 (범위: 0.0 ~ 10.0) / 크레이터 이동 거리: [0] mm (범위: 0.0 ~ 100.0)  
크레이터 처리 중에는 다운슬로프 시간과 조건 유지 시간 동안 로봇이 후진할 거리를 설정합니다. 속도는 거리와 시간에 따라 자동으로 결정됩니다.

{% hint style="info" %}
크레이터 이동 시 위빙 기능은 V70.04 부터 지원합니다.
{% endhint %}

### (7)	크레이터 이동 시 위빙 여부   
크레이터 처리 중 위빙을 할 것인지 안할 것인지를 설정합니다. (default : 미사용)

### (8)	크레이터 위빙 시 위빙 폭 [본조건의 %]
크레이터 처리 시 위빙 폭을 본조건 대비 몇 %으로 할 것인지 설정합니다. (100% 이면 본조건과 동일 폭)

### (9)	크레이터 위빙 시 주파수 [Hz]
크레이터 처리 시 위빙 주파수를 설정합니다.

### (10)	크레이터 와이어 제어
용접 종료 후 와이어 역인칭을 할 것인지 설정합니다.

### (11)	역인칭 시간 [sec]
용접 종료 후 역인칭할 시간을 설정합니다.

### (12)	역인칭 속도 [%]
용접 종료 후 역인칭 시 속도를 설정합니다.

### (13) 자동 용착 해제 횟수: [ 0 ] 회 (범위: 0 ~ 9) / 조건: [0] (범위: 0 ~ 32) / 시간: [0] s (범위: 0.0 ~ 10.0)  
Arc 용접 종료 시 와이어가 모재에 용착되는 경우가 있습니다. 용접기에서는 이를 방지하기 위해 용접 종료 시 일시적으로 전압을 상승시키는 용착 방지 처리를 합니다. 용접기에서 이런 처리 후에도 용착이 되는 경우가 있기 때문에 로봇 제어기에서도 용접 후 용착 검사 신호를 용접기로 전송하여 용착 여부를 확인합니다.  
자동 용착 해제 기능은 이렇게 용접 후에 용착이 검출될 때 자동으로 용착 해제를 수행하여 로봇이 정지하지 않고 연속적으로 작업할 수 있게 하는 기능입니다. 설정된 횟수만큼 반복되며, 횟수를 초과할 때까지 용착이 해제되지 않는 경우 로봇은 정지하게 됩니다.  

* 횟수: [ 0 ] 회 (범위: 0 ~ 9)
    용착 해제 처리 최대 반복 횟수입니다. 설정된 횟수 이내에 용착이 해제되지 않을 경우 에러가 발생합니다. 예외적으로 0으로 설정하면 용착 검사를 하지 않고 바로 다음 스텝으로 이동합니다.

* 조건: [0] (범위: 0 ~ 32)
    용착 해제 처리할 때 사용할 용접 조건의 번호입니다. "0"으로 설정할 경우 현재 실행중인 용접 시작 조건의 본 조건으로 수행됩니다.

* 시간: [0] s (범위: 0.0 ~ 10.0)
    용착 해제 조건의 출력을 유지하는 시간입니다.
