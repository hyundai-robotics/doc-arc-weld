# 9.1.1 基本功能

(1) 显示对话框

-  打开 'xlsm' 文件后点击 'Drawing Graph' 按钮。  
-  点击后会显示 'Arc Welding Data' 对话框。

![](../../_assets/9_1.png)<br>
*图 9.1 焊接数据图表*

(2) 选择 Arc 焊接数据文件

-  勾选 'Data' 后点击 'Load a file' 按钮。  
-  选择要确认的 Arc 焊接数据文件，如下所示。

![](../../_assets/9_2.png)<br>
*图 9.2 焊接数据文件*

(3) 设置搜索条件

-  输入所需的搜索条件。 （如果不输入，将加载所有焊接数据）
-  按下 'List up' 按钮后，焊接信息将如下面所示显示。

![](../../_assets/9_3.png)<br>
*图 9.3 焊接信息列表*

(4) 选择数据

-  从显示的列表中选择一个。
-  对应的焊接图表将显示在 Excel 的图表中。

![](../../_assets/9_4.png)<br>
*图 9.4 选择焊接数据*
