# 7.4.1 아크 용접


최초 "아크 모니터링" 화면에 진입하면 열리는 화면입니다. 다른 화면에서 전환 시 하단 패널의 `[F1: 아크 용접]`을 클릭합니다.  
이 화면에서는 용접기와 주고 받는 데이터에 대한 아날로그, 디지털 신호들을 보여줍니다.

![](../../_assets/7_4_1_1.png)<br>
*그림 7.4.1.1. 아크 용접 모니터링*  

"아크 용접" 화면에서 하단 패널의 `[F7: 선택]` 버튼을 클릭하면 패널 내용이 바뀌며 다음과 같은 기능들을 사용할 수 있습니다.  


### (1) 용접기 선택

![](../../_assets/7_4_1_2.png)<br>
*그림 7.4.1.2. 용접기 수동 설정*  

하단 패널의 `[F1: 용접기 선택]` 버튼을 클릭하면 다음과 같은 창이 나타납니다. 여기서 용접기 수동 설정이 가능합니다.  


### (2) 수동 출력

![](../../_assets/7_4_1_3.png)<br>
*그림 7.4.1.3. 수동 출력*  

아날로그 출력 신호와 디지털 출력 신호 중에서 출력하고 싶은 신호의 칸을 선택하고(그림의 예시는 "용착 검사" 혹은 "OFF (fb1.12)") 하단 패널의 `[F2: 수동 출력]` 버튼을 클릭하면 다음과 같은 창이 나타납니다.
여기서 해당 신호이 출력되게 설정할 수 있습니다.  


### (3) I/O 설정

로봇 제어기와 용접기 간 주고 받는 데이터는 아날로그와 디지털 신호로 종류가 많습니다(`[F2: 시스템] - 5: 초기화 - 3: 용도설정 - [F2: 용접기 설정]` 참고).
하지만 실제 작업자가 모니터링하고 싶은 신호는 제한적입니다. 하단 패널의 `[F3: I/O 설정]` 버튼을 클릭하면 다음과 같은 창이 나타납니다.

![](../../_assets/7_4_1_4.png)<br>
*그림 7.4.1.4. I/O 출력 설정*  

이 창에서 보여지는 항목들은 로봇 제어기와 용접기가 주고 받는 모든 신호들을 보여줍니다. 여기서 필요한 데이터만 선택하여 `OK`를 클릭하면 해당 데이터만 모니터링 가능합니다. 이때 상단의 `전체 선택`, `전체 초기화` 버튼을 눌러 전부 설정하거나 해제할 수 있습니다.
