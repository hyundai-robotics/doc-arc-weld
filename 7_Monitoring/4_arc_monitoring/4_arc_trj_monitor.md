# 7.4.4 아크 궤적 모니터링


본 기능을 사용하려면 우선 `[F2: 시스템] - 4: 응용파라미터 - 2: 아크용접` 에서 **"아크 궤적 모니터링"** 을 **'유효'** 로 설정해야 합니다.  

이제 "아크 모니터링" 화면에서 `[Shift] + [ESC]` 버튼을 클릭하여 전체 화면이 되도록 전환합니다. 좌측에는 하단 패널에서 선택하는 표 데이터가, 우측에는 "아크 궤적 모니터링" 화면이 나타납니다. 이 화면에서는 아크 용접을 수행할 때 궤적, 토치의 자세(작업각, 푸쉬풀각)를 실시간으로 보여줍니다.  
(`arcon` 부터 `arcoff` 구간 까지의 궤적 및 용접정보를 실시간으로 확인할 수 있습니다)


![](../../_assets/7_4_4_1.png)<br>
*그림 7.4.4.1. 아크 궤적 모니터링*  


가운데를 클릭하여 움직이면 표와 캔버스 크기를 조절할 수 있습니다(단 한 화면을 아예 가리는 것은 불가능하며, 화면을 축소했다가 다시 전체 화면으로 전환 시 초기화됩니다). 화면 내의 `+/-` 키와 `[shift]` 버튼을 눌러 확대 혹은 축소가 가능합니다.  
캔버스 내에서는 드래그를 하여 화면의 위치를 조정할 수 있습니다.
