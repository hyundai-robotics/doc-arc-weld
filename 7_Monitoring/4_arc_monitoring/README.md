# 7.4 아크 통합 모니터링

{% hint style="info" %}
해당 기능은 70.00-00 이후 버전에서 지원합니다.
{% endhint %}

본 기능을 통해 아크 용접과 관련된 모니터링 기능을 한 화면에서 볼 수 있습니다.
기존 아크 용접, 실시간 용접 데이터 변경 기능, 아크 센싱과 멀티 패스, 아크 가동 정보, 아크 궤적 모니터링 기능이 합쳐져 있습니다.  

이 기능을 사용하려면 `[(우측 패널)창조정] - 선택 - 아크 모니터링`을 순차적으로 눌러 진입합니다.
다음 장에서 각 화면 전환과 모니터링 기능들을 설명합니다.
