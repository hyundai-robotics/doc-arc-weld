# 8.7 LPS(Laser Point Sensing)  

{% hint style="info" %}
해당 기능은 70.00-00 이후 버전에서 지원합니다.
{% endhint %}

본 기능은 터치 센싱과 같은 기능적 효과-용접 시작점과 경유점, 종료점을 검출-를 위해 사용합니다. 터치 센싱은 용접 와이어가 모재에 직접적인 터치가 있어야 하므로 수행 시간이 오래 걸리고, 용접건에 의한 간섭이 발생할 수 있습니다.
이를 보완하기 위해 1D 타입의 레이저 변위 센서를 이용한 레이저 포인트 센싱(이하 LPS) 기능을 사용합니다. 레이저를 이용하여 시간은 단축하고, 간섭에 제한을 줄였기 때문에 간단한 조건으로 더 쉽고 빠르게 용접점을 검출할 수 있습니다.


최초 용접건이 달린 툴 플랜지에 브라켓을 이용해 레이저 센서를 설치하고 툴-센서 간 캘리브레이션을 1회 진행하면, 레이저가 가리키는 지점의 포즈를 쉽게 구할 수 있습니다. 또 단차 검출뿐만 아니라 별다른 조건 설정 없이 어떤 모재의 형상이든 용접점의 포즈를 쉽게 얻을 수 있습니다.

터치 센싱과 마찬가지로 마스터 모드 사용이 가능하며 작업물이 들어왔을 때 기준으로부터 얼마나 쉬프트 되어있는지 자동으로 계산할 수 있습니다.
