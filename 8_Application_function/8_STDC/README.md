# 8.8 STDC(Sensor-based Tool Data Correction)  

{% hint style="info" %}
해당 기능은 70.04-00 이후 버전에서 지원합니다.
{% endhint %}

산업용 로봇에서 반복된 작업의 품질을 보장하기 위해서는 TCP의 위치가 일정하게 유지되어야 합니다. 그러나 주변 장치와의 충돌이나 반복된 열변형 등으로 툴이 변형될 경우 기존 교시 위치와 실제 작업 위치 사이에 오차가 발생할 수 있습니다.  

이러한 오차는 툴을 물리적으로 복원하거나 TCP를 재설정하여 보정할 수 있습니다. 그러나 물리적인 복원에는 별도의 지그와 수동 작업이 필요하며, 설비 구조나 작업 환경에 따라 복원 작업이 어려울 수 있습니다. 또한 TCP를 재설정하는 과정 역시 시간이 많이 소요됩니다.  

툴 자동 보정 기능은 센서를 이용하여 툴의 변화량을 측정하고, 측정된 오차만큼 TCP를 자동으로 보정하는 기능입니다. 이를 통해 별도의 복원 및 재교시 작업을 최소화하고 작업 위치를 보정할 수 있습니다.
