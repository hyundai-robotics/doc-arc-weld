# 8.8.3 툴 자동 보정 기능 사용

툴 자동 보정 기능은 총 3개의 잡 프로그램을 사용하여 수행합니다. 본 장에서는 각 잡 프로그램의 역할과 사용자가 직접 설정해야 하는 항목을 중심으로 설명합니다.


### (1) 101번 잡(메인 - 사용자 설정)

![](../../_assets/8_8_3_1.png)<br>
*그림 8.8.3.1. 101.job*

101번 잡은 사용자가 직접 설정하는 메인 프로그램입니다. S1의 `move` 문에서 target으로 시스템 변수 `_stdc_cnd.pose`를 설정합니다. 이때 적용되는 포즈는 측정 모드에 따라 다음과 같이 결정됩니다.
- **기준 등록 모드**: 저장된 기준 포즈가 없으므로 현재 로봇의 포즈를 사용합니다. 따라서 최초 프로그램을 작성하여 수행할 때 로봇을 교시해야 합니다. 교시 위치는 센서의 X/Y축이 모두 툴을 감지할 수 있는 센서 중심 부근으로 설정해야 합니다.  

- **보정 모드**: 기준 등록 시 저장된 포즈를 사용합니다.  

{% hint style="warning" %}
  현재 위치에서 target 포즈로 이동할 때 충돌하지 않도록 주의해야 합니다.
{% endhint %}  

이후 `call` 문을 사용하여 102번 잡을 호출합니다. 다음 예시에서 각 파라미터의 의미는 다음과 같습니다.  

```call 102,25,12```

- **102**: 호출할 잡 프로그램의 번호
- **25**: 원 운동의 반지름
- **12**: 툴의 Z 방향 이동량


### (2) 102번 잡(메인 - 동작 수행)

![](../../_assets/8_8_3_2.png)<br>
*그림 8.8.3.2. 102.job*

102번 잡은 센서를 이용한 측정 및 툴 보정 동작을 수행하는 프로그램입니다.  

먼저 서로 다른 높이에서 두 번의 원 운동을 수행하여 각각의 센서 중심을 측정합니다. 측정된 두 중심 위치를 이용하여 툴의 각도 변형량을 계산하고 보정을 수행합니다(`opt=3`).

각도 보정이 완료되면 세 번째 원 운동을 수행하여 보정된 툴을 센서 중심에 정렬합니다. 이후 센서의 Z 방향으로 직선 운동을 수행하여 툴 끝단을 센서 중심에 위치시킵니다. 이 과정에서 설정된 측정 모드에 따라 기준 등록 또는 보정에 필요한 정보가 저장됩니다(`opt=5`).  


### (3) 110번 잡(원 동작 및 중심 계산)

![](../../_assets/8_8_3_3.png)<br>
*그림 8.8.3.3. 110.job*

110번 잡은 102번 잡에서 전달된 파라미터를 이용하여 센서 중심 측정을 위한 원 운동을 수행합니다.  

전달된 중심 좌표, 원의 법선 벡터, 반지름 등의 파라미터를 기반으로 4분원 위치를 계산합니다. 계산된 위치를 따라 툴을 이동시키며 센서 데이터를 수집하여 툴이 통과하는 센서 중심 위치를 계산합니다.
