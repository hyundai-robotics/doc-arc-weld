# 8.6.3 stitch 기능 파라미터 설정


![](../../_assets/8_6_5.png)<br>
*그림 8.6.5. 스티치 용접 과정에 따른 Profile*

[그림 8.6.5]는 스티치 용접 과정을 보여줍니다. 이 차트에 따라 `stitch` 명령어의 옵션들을 설정할 수 있습니다.

![](../../_assets/8_6_6.png)<br>
*그림 8.6.6. 스티치 용접 조건 대화상자1*

![](../../_assets/8_6_7.png)<br>
*그림 8.6.7. 스티치 용접 조건 대화상자2*


[그림 8.6.6]은 `stitch` 명령어에 커서를 두고 TP 좌측 화면에서 [속성] 버튼을 눌러 접근할 수 있습니다. [그림 8.6.7]은 이전 화면에서 [구분] 탭을 눌러 접근합니다. 각 그림에 대한 파라미터 설명은 다음과 같습니다.


- 조건 번호 : 우측 조건 목록에서 선택 
- 설명 : 소프트 키보드로 입력
- 일반
  - (1) ON 유지 시간 : 용접 신호가 미리 켜지는 시간
  - (2) OFF 유지 시간 : 용접 신호가 미리 꺼지는 시간
  - (3) 시작 거리 : 스티치 시작 전 On 구간 속도 진입 구간 길이
  - (4) OFF 속도 : 비용접 구간 용접 속도
- 구분
  - (5) 구분 : 스티치 용접 조건  
    Ex- 구분 1 조건의 스티치 용접이 해당 count만큼 진행되면 구분 2의 조건에 해당하는 스티치 용접이 진행됨
  - (6) ON 거리 : 용접 구간 길이
  - (7) OFF 거리 : 비용접 구간 길이
  - (8) 횟수 : Stitch 용접 횟수
  - (9) ON 속도 : 용접 구간 용접 속도 

{% hint style="warning" %}
- (9) ON 속도 : 스티치 구간에서 용접(ON) 구간의 속도 설정은 스텝 속도로 지정
{% endhint %}
