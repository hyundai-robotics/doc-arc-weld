# 8.9 마스터모드/양산모드

### (1) 개요  

마스터모드/양산모드는 기준 작업물에서 얻은 포즈를 저장하고, 양산 작업물에서 얻은 포즈와 비교하여 작업물의 위치 차이를 시프트로 계산하는 기능입니다.

* **마스터모드(On)**: 기준 작업물을 센싱하여 마스터 포즈를 등록합니다.
* **양산모드(마스터모드 Off)**: 양산 작업물을 센싱하고 마스터 포즈 대비 시프트를 계산합니다.

마스터모드는 **[사용자키] - [마스터 모드]** 에서 On/Off 할 수 있습니다.

| 구분 | 마스터모드(On) | 양산모드(Off) |
| :--- | :--- | :--- |
| 센싱 포즈 `sp` | 현재 센싱 또는 계산 결과 저장 | 현재 센싱 또는 계산 결과 저장 |
| 마스터 포즈 `mp` | `sp`와 같은 결과를 저장하여 기준 위치 갱신 | 등록된 기준 위치를 참조하며 갱신하지 않음 |
| 마스터 시프트 `ms` | 시프트를 0으로 초기화 | 현재 결과와 마스터 포즈의 위치 차이를 저장 |

시프트는 지정된 계산 좌표계에서 **현재 센싱 위치 - 마스터 위치** 방향으로 계산됩니다. 위치 성분 X, Y, Z를 계산하며, 회전 성분 Rx, Ry, Rz는 0입니다. 따라서 이 기능만으로 작업물의 회전 오차까지 보정하는 것은 아닙니다.


### (2) 적용 명령어  

| 명령어 | 마스터모드/양산모드 적용 대상 | 결과 |
| :--- | :--- | :--- |
| `touchsen` | 터치센싱 | 센싱한 포즈를 기준으로 등록 또는 시프트 계산 |
| `lvs` | `seam_find`, `seam_find_p`, `intersection`, `step_search` | 검출하거나 계산한 포즈를 기준으로 등록 또는 시프트 계산 |
| `lps` | `spot`, `stepp`, `scan` | 검출한 포즈를 기준으로 등록 또는 시프트 계산 |
| `arc_intersect` | 참조 포즈 3개 또는 4개를 이용한 교차점 계산 | 계산한 포즈를 기준으로 등록 또는 시프트 계산 |

* 참고  
`lvs search`, `lvs check_seam`은 `sp`가 필요하지만, 위의 `mp`/`ms` 처리가 적용되는 명령은 아닙니다. `lvs track`의 `sp`는 선택 인자입니다.  

명령어별 상세 사용법은 [2.7 lvs](../../2_Command/7_lvson.md), [2.8 lps](../../2_Command/8_lps.md), [2.13 touchsen](../../2_Command/13_touchsen.md), [2.15 arc_intersect](../../2_Command/15_arc_intersect.md)를 참고하십시오.  


### (3) 공통 인자 및 변수 생성

| 인자 | 변수 타입 | 용도 | 지정한 변수가 아직 정의되지 않은 경우 |
| :--- | :--- | :--- | :--- |
| `sp` | 포즈 | 현재 센싱 또는 계산 결과 저장 | 지역 포즈 변수로 자동 생성 |
| `mp` | 포즈 | 기준 위치 저장 및 참조 | 마스터모드에서만 전역 포즈 변수로 자동 생성 |
| `ms` | 시프트 | 기준 위치 대비 시프트 저장 | 마스터모드에서만 전역 시프트 변수로 자동 생성 |

자동 생성은 **인자에 유효한 변수 이름을 지정했으나 해당 변수가 정의되지 않은 경우**에 수행됩니다. 인자 자체를 생략해도 자동으로 이름이 정해지거나 변수가 생성되는 것은 아닙니다. 이미 정의된 변수는 지정한 변수 그대로 사용하므로 포즈/시프트 타입을 확인하십시오.

양산모드에서는 `mp`, `ms`에 지정한 변수가 미리 정의되어 있어야 합니다. 실제 기준 위치가 등록되어 있는지도 확인해야 하며, 단순히 변수를 선언한 것만으로 마스터 티칭을 대신할 수는 없습니다.

{% hint style="warning" %}
일반적으로 `sp` 인자만 사용하나 마스터모드에서는 `mp`, `ms` 인자를 모두 지정해야 합니다. 다만 `arc_intersect`는 항상 모든 인자를 지정해야 합니다.
{% endhint %}


### (4) 사용 순서

#### 1. 마스터 티칭

1. 기준 작업물을 설치하고 센서 설정, 센싱 조건 및 계산 좌표계를 확인합니다.
2. 각 센싱 시작 위치를 티칭하고 센싱 경로를 확인합니다.
3. **[사용자키] - [마스터 모드]** 를 On으로 설정합니다.
4. `sp`, `mp`, `ms`를 지정한 명령어를 실행합니다.
5. 각 지점의 `mp`에 기준 포즈가 저장되고, `ms`가 0으로 초기화되었는지 확인합니다.
6. 마스터 등록을 완료한 뒤 마스터모드를 Off로 설정합니다.

#### 2. 양산 작업

1. 양산 작업물을 설치하고 마스터모드가 Off인지 확인합니다.
2. 마스터 티칭 때와 같은 지점에 대응하는 `mp`, `ms` 변수를 사용하여 센싱 명령어를 실행합니다.
3. `sp`에 현재 결과가 저장되고, `ms`에 기준 위치 대비 시프트가 계산됩니다.
4. 계산된 시프트와 좌표계를 확인한 뒤 작업 경로의 위치 보정에 사용합니다.

{% hint style="warning" %}
* 양산 중 마스터모드를 On으로 실행하면 현재 작업물의 결과로 마스터 포즈가 갱신됩니다. 기준 위치를 다시 등록하려는 경우가 아니라면 마스터모드를 Off로 유지하십시오.
* 서로 다른 센싱 지점은 별도의 마스터 포즈와 시프트 변수로 관리하십시오. 같은 변수를 재사용하면 이전 지점의 결과가 덮어써집니다.
* 센싱 조건, 툴 또는 좌표계가 바뀐 경우에는 기존 마스터 포즈를 그대로 사용하기 전에 기준 위치와 시프트 계산 결과를 확인하십시오.
{% endhint %}


### (5) 사용 예

아래 예시는 인자 지정 방법을 설명하기 위한 명령문입니다. 각 명령은 해당 센서와 조건이 설정되고 센싱 시작 위치에 도달한 상태를 전제로 합니다. 실제 작업물에 맞는 조건, 방향, 이동거리 및 속도를 설정한 뒤 사용하십시오.  

```python
    # 터치센싱
    touchsen cnd=1,crd="robot",dir="+y",sp=p10,mp=mp10,ms=ms10

    # LVS 센싱 결과를 이용한 마스터 등록/시프트 계산
    lvs seam_find,cnd=1,seam=10,sp=p10,mp=mp10,ms=ms10

    # LPS 센싱 결과를 이용한 마스터 등록/시프트 계산
    lps scan,cnd=1,Tx=50,spd=10,sp=p20,mp=mp20,ms=ms20
```  

* 마스터모드를 Off로 하고 단순히 센싱 포즈만 얻으려는 경우에는 `mp`, `ms`를 **모두 생략**합니다.
