# 2.10 heightsen off

### Description

```heightsen off``` 命令用于停止高度感应功能 (AVC, Arc Voltage Control)。

<br/>

### Syntax
  
```python
heightsen off
```  

### Example

```python   
   heightsen off            # 结束高度感应执行
```
