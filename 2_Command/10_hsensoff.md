# 2.10 heightsen off

### Description

```heightsen off``` command is used to stop the height sensing function (AVC, Arc Voltage Control).

<br/>


### Syntax
  
```python
heightsen off
```  


### Example

```python   
   heightsen off            # End height sensing execution
```
