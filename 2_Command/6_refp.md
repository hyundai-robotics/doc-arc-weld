# 2.6 refp

### 描述

```refp``` 命令用于输入编织运动的参考点。它输入参考点，例如编织墙和入口方向。
<br/>

### 语法

```python
refp <参考点编号>
refp <参考点编号>,<姿态(数字)>
```  

### 参数

| 项目 | 含义 | 备注 |
| --- | --- | --- |
| **参考点编号** | 设置参考点类型的编号 (1 ~ 8) | 可变 |
| **姿态** | 输入参考点的姿态 (不过，如果使用隐藏姿态，将被省略) | 可变 |


### 示例

```python
   refp 1,P1                   # 使用 P1 指定编织的墙方向
   refp 1                      # 指定编织的隐藏姿态的墙方向
   refp 2, (-1073.33, 739.01, 258.30, 0, 76, 23)  # 指定编织表面的位置信息
```
